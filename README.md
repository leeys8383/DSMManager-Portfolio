# DSM Manager

### Windows 업무관리 프로그램 | C# · WPF · SQLite

DSM Manager는 소규모 제조업 및 유통업체의 거래처, 품목, 재고, 거래내역을 통합 관리하기 위해 개발한 Windows 데스크톱 애플리케이션입니다.

실제 업무 사용자의 요구사항을 반영하여 개발했으며, Microsoft Store에 정식 게시했습니다.

## 주요 기능

**1. 거래처 관리**
- 거래처 등록, 수정 및 조회
- 매입처·매출처 구분
- 담당자 및 연락처 관리
- 사용 중지 및 재사용 관리

**2. 품목 및 재고 관리**
- 품목별 규격과 세부 속성 관리
- 재고 입출고 및 수량 변동 관리
- 품목 사용 상태 관리

**3. 거래내역 관리**
- 거래일자, 수량, 단가, 공급가액, 부가세 및 합계금액 관리
- 일별·월별·기간별 거래내역 조회
- 거래금액 및 거래량 기준 정렬

**4. 사용자 편의성**
- 업무 담당자의 사용 환경을 고려한 화면 설계
- 가독성을 높인 글자 및 버튼 크기
- 날짜 선택 및 데이터 입력 편의성 개선
